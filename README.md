# Tema Neon Eclipse (Cyberpunk) para Kino — v1.1.0

Tema oscuro cyberpunk (`apiVersion: 26`) con **pantalla de presentación y selector interactivo de temas** (`plugin.js`) + 3 variantes visuales y logotipo vectorial **KINO**.

## Novedades v1.1.0
- **Pantalla de presentación / Selector de temas**: al abrir el plugin en Kino muestra un hero de presentación cyberpunk y las 3 tarjetas de temas para aplicarlos con un clic.
- **3 variantes incluidas**:
  1. **Neon Eclipse**: fondo urbano nocturno (`assets/background.png`) + acento rosa neón (`#FF2A85`).
  2. **Neon Eclipse (Degradado)**: degradado púrpura nocturno sin imagen externa (ideal si Windows bloquea fondos locales).
  3. **Neon Eclipse (Cyber Cian)**: estética cian eléctrico (`#5CE1E6`) con acentos magenta.

## Instalación
1. Sube todos los archivos de este ZIP a la raíz de `https://github.com/agapito309pro/tema-neo` reemplazando los anteriores.
2. En Kino (Windows o Android), abre **Ajustes ▸ Plugins** e instala `agapito309pro/tema-neo`.
3. Abre el plugin **Neon Eclipse** desde el menú lateral para ver la pantalla de presentación y elegir tu tema, o selecciónalo en **Ajustes ▸ Apariencia**.
