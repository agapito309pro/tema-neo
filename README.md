# Tema Neon Eclipse para Kino

Tema de app completo (`apiVersion: 26`) inspirado en un horizonte urbano nocturno con anillo neón rosa-magenta y destellos cian, construido a partir de la estructura base del plugin de tema para Kino.

## Instalación

En Kino: **Ajustes ▸ Plugins** → instala el paquete o repositorio del tema y luego ve a **Ajustes ▸ Apariencia** para seleccionar **Neon Eclipse** o **Neon Eclipse (Degradado)**.

Para personalizar: **Ajustes ▸ Apariencia ▸ Personalizar** (disponible cuando el tema está activo).

## Variantes incluidas

- **Neon Eclipse**: utiliza la imagen adjunta (`assets/background.png`) como fondo con `fit: "cover"` y `dim: 0.5`, combinada con superficies violeta-oscuro y acento rosa neón (`#FF2A85`).
- **Neon Eclipse (Degradado)**: utiliza un degradado nocturno en tonos púrpura y magenta (`#090312` → `#3B0E47` → `#090312`) sin depender de la imagen de fondo.

## Compatibilidad

- Requiere **Kino 0.9.87 o posterior** y `apiVersion: 26`.
- Conserva la estructura nativa de selección y tarjetas (`cardBorder: 0`, sin superficies pintadas personalizadas).
