# Tema Neon Eclipse (Cyberpunk) para Kino

Tema oscuro cyberpunk (`apiVersion: 26`) inspirado en un horizonte urbano nocturno con anillo neón rosa-magenta, destellos cian y logotipo vectorial **KINO**.

## Instalación en Kino

1. Sube todos los archivos de este ZIP a la raíz de tu repositorio `https://github.com/agapito309pro/tema-neo` (reemplazando los anteriores para que `assets/background.png` coincida exactamente con su `sha256`).
2. En Kino (Windows o Android), ve a **Ajustes ▸ Plugins** y escribe:
   ```
   agapito309pro/tema-neo
   ```
3. Ve a **Ajustes ▸ Apariencia** y elige **Neon Eclipse** o **Neon Eclipse (Degradado)**.
