# Neon Eclipse · tema cyberpunk para Kino

Tema para **toda la app** de Kino (celular, escritorio y TV) inspirado en el horizonte urbano nocturno con anillo neón rosa-magenta y destellos cian, con logotipo vectorial **KINO** y pantalla de presentación.

No usa la red (`"hosts": []`) y no pide permisos. Guía oficial: <https://kinotvapp.github.io/kino-plugins/themes/>

## Variantes incluidas

| id | Nombre | Acento | Estilo |
|---|---|---|---|
| `neon-eclipse-horizon` | Horizonte Neón | `#FF2A85` | degradado oscuro `#090212` → `#2B083D`, bordes suaves, deriva activa |
| `neon-eclipse-magenta-grid` | Pulso Magenta | `#FF4DA6` | degradado `#0B0210` → `#330838`, bordes `2 dp`, experiencia ligera |
| `neon-eclipse-cyber-cyan` | Ciber Cian | `#5CE1E6` | degradado `#030914` → `#0B2340`, cortes rápidos de `80 ms`, experiencia ligera |
